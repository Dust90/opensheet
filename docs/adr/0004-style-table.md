# ADR-0004: 工作簿级样式表（哈希去重）

## 状态

已接受（M0 实现）

## 背景

百万级单元格若各自内联样式对象，内存将随单元格数线性膨胀；而真实表格中绝大多数单元格共享少数几种样式。

## 决策

- 单元格只存 `styleId` 字符串引用。
- `Workbook.styles`（`StyleTable`）按样式内容的规范化哈希去重：相同属性组合（无论键序）返回同一 id。
- 样式表随 Snapshot 持久化，单元格 `styleId` 跨保存/加载保持稳定。

## 理由

10w 有值单元格 × 相同样式时，内存差距是数量级的；去重也让"修改一种样式"成为 O(1) 操作。

## 后果

- `styleId` 由内容决定（不可读），调试时需查表；可接受。
- 样式合并语义（粘贴时如何取舍）推迟到 M2 剪贴板实现时定义。
